## 📋 Project Description

This is a responsive developer portfolio showcasing my skills, projects and background as a fullstack developer with experience in Java, C# and web design. The portfolio includes a contact form, live weather data and several CSS animations.

---

## ✨ Features

- Responsive design that adapts to mobile and desktop
- Animated typing effect in the hero section
- Scroll-triggered animations on skill cards
- Contact form with real email functionality via EmailJS
- Live weather data for Stockholm via OpenWeatherMap API
- Downloadable CV
- Smooth scroll navigation with sticky navbar
- Mobile hamburger menu

---

## 🛠️ Technologies Used

- **HTML5** — semantic structure
- **CSS3** — styling and animations
- **JavaScript (Vanilla)** — interactivity and API calls
- **EmailJS** — contact form email functionality
- **OpenWeatherMap API** — live weather data
- **Devicons** — technology icons in the skills section
- **Google Fonts (Poppins)** — typography

---

## 📐 Methods & Principles Used

- **CSS Custom Properties (Variables)** — all colors and gradients defined as variables under `:root` for easy theming
- **Flexbox** — used throughout for layout, alignment and responsive behavior
- **CSS Grid** — used in the skills section for card layout
- **Media Queries** — responsive breakpoints at 916px, 750px and 650px
- **CSS Animations & Transitions** — typing effect cursor blink, hover transitions on cards and buttons
- **Intersection Observer API** — used to trigger scroll animations on skill cards when they enter the viewport
- **Fetch API** — used to retrieve live weather data from OpenWeatherMap
- **Form Validation** — client-side validation with error messages before form submission
- **BEM-inspired naming** — class names follow a clear and consistent naming convention
- **DRY principle** — reusable classes like `.btn`, `.section-title` used across multiple sections

## 🚀 How To Run Locally

1. Clone the repository:
```
git clone https://github.com/AlemiMahdi/portfolio
```
2. Open the project folder
3. Open `index.html` with Live Server in VS Code

No installations or dependencies needed — the project runs entirely in the browser.
